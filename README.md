# BRS PDF Suite for Windows

Free PDF tools for CA offices and small businesses. Everything runs on your own computer: no upload, no account, works offline.

**Download:** [latest installer](https://github.com/imumehta/brs-pdf-suite/releases/latest) (Windows 10/11, 64-bit).
Each release lists a SHA-256 checksum in `SHA256SUMS.txt`.

## What it does

- PDF viewer (default PDF app if you want it)
- Merge, split, organise pages, compress, page numbers, watermark, stamp
- OCR: make scanned PDFs searchable (English, Hindi, Gujarati)
- Edit PDF: change existing text, white-out, add text, images, highlights and drawings
- Digital signature with a Class 3 DSC (USB token or .pfx file)
- Protect / unlock, redact, PDF to Word/Excel/text, images to PDF and back

## Updates

The app checks this page once a day for a newer version (you can switch it off in the ⋯ menu).
It sends nothing about you or your documents.
